About TravelGraph

TravelGraph is a college Data Structures & Algorithms project that demonstrates graphs, weighted graphs, adjacency lists, priority queues, and Dijkstra's shortest-path algorithm inside a real-feeling travel planning application.

Graph

A collection of vertices (cities) connected by edges (roads). In TravelGraph, each city is a vertex, and each direct road connection between two cities is an edge.

Weighted Graph

A graph whose edges carry a numeric value — here, the approximate distance in kilometers between two directly connected cities.

Adjacency List

Each city stores a dictionary of its directly connected neighbouring cities and the distance to each. This is more memory-efficient than an adjacency matrix for sparse graphs like a road network.

Priority Queue

Dijkstra's algorithm needs to repeatedly find the unvisited city with the smallest known distance. A min-heap priority queue (Python's heapq) makes this efficient — O(log n) per insertion/removal instead of scanning the whole list.

Dijkstra's Algorithm

A greedy shortest-path algorithm that, starting from the source, finalizes the shortest distance to one new city at a time until the destination is reached, using the priority queue to always expand the currently-closest city.

Real-World Applications

  • GPS navigation systems
  • Computer network routing
  • Logistics and supply chain planning
  • Delivery and courier systems
  • Public transportation planning
  • Digital maps and route planners

How It Works Together

The cities are represented as vertices in a weighted graph. The roads between them are weighted edges where the weight represents an approximate distance, stored using an adjacency list. When a user selects a source and destination, a hand-written implementation of Dijkstra's algorithm — using a priority queue — finds the shortest path through that graph. The resulting city path is then displayed on an interactive map, with OpenStreetMap and OSRM used only to draw realistic road geometry for that already-determined path.
